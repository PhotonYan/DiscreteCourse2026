## 本讲的几个"必须写清"的点

- **手写稿底部的 $A_m=\sum_{k\ge0}\binom{k}{m}2^{-k}$ 是另一个和（恒等于 $2$），不要与 $A_n=\sum_k\binom nk2^{-k}=(3/2)^n$ 读混**；两种和的递推不同（详见第 2 节勘误）。
- **卡特兰数公式**：$C_n=\frac1{n+1}\binom{2n}{n}$，下标 $n$ 对应"$n$ 对括号 / $(n+2)$ 边形 / $n+1$ 个符号"；手写稿的 $C_{2n}$ 是笔误。
- **球桶四类**：$m^n$（可区分球、可区分桶、允许空）、满射数（可区分球、可区分桶、非空）、$\binom{n-1}{m-1}$（相同球、非空）、$\binom{n+m-1}{m-1}$（相同球、允许空）。
- **容斥**：并集公式符号为 $(-1)^{|S|+1}$；满射与错排是标准应用。
- **抽屉原理**：$rs+1$ 项的 Erdős–Szekeres 定理；有重复元素时要改用非降/非升版本。
