# Lec 14：Burnside 引理与 Pólya 计数

本讲从第 13 讲的 EGF 例子出发，转向“**对称意义下数对象**”的计数：先证明 Burnside 引理（轨道数 = 不动点数的平均），再把群元素的轮换结构编码成循环指数，得到 Pólya 计数定理；最后用它处理无标号有根树与染色计数。

**来源说明。** 本讲原始材料是**三页手写稿**与**两段课堂转写**。但两段转写中第一段只有一句“。”，实际可用的是第二段（从项链/二面体染色讲到无标号树）；手写稿第 1 页还包含 EGF 回顾（带标号二叉树、排列与轮换），这部分转写缺失。整理版按“手写稿 + 可用转写 + 课程讲义 §9.10–9.12、[DS] 第 14 章”取并集，缺少出处的地方以教材补全。

## 记号速查

- $G\times S\to S$：群作用；$\operatorname{Orb}(x)$、$\operatorname{Stab}(x)$、$S/G$、$\operatorname{Fix}(g)$。
- $c_i(g)$：置换 $g$ 中长度为 $i$ 的轮换个数；$Z_G(t_1,t_2,\dots)$：循环指数。
- $C_n$：循环群（本节不指卡特兰数）；$D_n$：$2n$ 阶二面体群。
- $C$：颜色数；$w_j$：第 $j$ 种颜色的权重；$R(x)$：无标号有根树的 OGF。

## 本讲的几条主线

1. **Burnside 引理**：$|S/G|=\frac1{|G|}\sum_{g\in G}|\operatorname{Fix}(g)|$；用双计数证明，把“轨道数”化为“每个群元素固定多少对象”的平均。
2. **循环指数**：把每个 $g$ 的轮换型编码成单项式 $t_1^{c_1}t_2^{c_2}\cdots$，对群取平均得到 $Z_G$；循环群与二面体群的 $Z_G$ 有闭式。
3. **Pólya 计数**：把 $t_i$ 换成颜色权重的 $i$ 次幂之和，得到按颜色使用次数计权的生成函数；令所有权重为 $1$ 就得到染色轨道数。
4. **无标号树**：把“孩子”看成无序多重集，用 $S_3$ 的循环指数写出 $R(x)=1+\frac{x}{6}(R^3+3RR(x^2)+2R(x^3))$，展开得 $1,1,2,4,8,17,\dots$。

## 勘误与提醒

- **$D_n$ 的阶是 $2n$**：本讲公式分母用 $2n$；[DF] 把正方形对称群记作 $D_8$，即本讲的 $D_4$。
- **Pólya 代入的是 $t_i=\sum_j w_j^i$**，不是 $t_i=\sum_j w_j$；指数 $i$ 来自轮换长度。
- **无标号树不能用 EGF 的 $\exp$**：第 13 讲的 EGF set 构造只适用于带标号对象；无标号要用 OGF + Pólya（或 Burnside）。
- **$R=1+\frac{x}{6}(\cdots)$ 与 $R=x(\cdots)$ 两种写法只差“空树是否计入”**；前者常数项为 $1$，后者常数项为 $0$，系数相同。
- 转写把“Burnside/Pólya/轮换/二面体”等识别得较乱（如“办公式”“软柿子”“公元”）；术语以整理版与讲义为准。
