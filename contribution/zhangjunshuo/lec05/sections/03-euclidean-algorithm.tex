\section{扩展欧几里得算法}


\subsection{算法与返回值}


输入 $0\le a\le b$，返回 $(d,u,v)$，满足 $d=\gcd(a,b)=au+bv$。

\begin{verbatim}
ExtendedGCD(a, b):
    if a == 0:
        return (b, 0, 1)
    q, r = divmod(b, a)
    d, u, v = ExtendedGCD(r, a)
    return (d, v - q*u, u)
\end{verbatim}


一般整数输入可先对绝对值排序求解，再把交换和符号还原到系数上。

\subsection{终止性与正确性}


递归时第一参数从 $a$ 变为 $r$，且 $0\le r<a$；非负整数不能无限严格下降，所以算法终止。

由 $b=aq+r$，有

\[
d\mid a,b\quad\Longleftrightarrow\quad d\mid r,a,
\]

所以 $\gcd(a,b)=\gcd(r,a)$。基例 $a=0$ 返回 $b$，也符合 $\gcd(0,0)=0$ 的约定。

若内层已给出 $d=ru+av$，则

\[
d=(b-aq)u+av=a(v-qu)+bu.
\]

这验证了返回系数。最大公因数、最小正线性组合和算法输出因而一致（最小正线性组合要求输入不全为零）。

\subsection{例：求 gcd 与系数}


对 $252,198$ 辗转相除：

\[
\begin{aligned}
252&=198+54,\\
198&=3\cdot54+36,\\
54&=36+18,\\
36&=2\cdot18.
\end{aligned}
\]

故 $\gcd(252,198)=18$。回代得到

\[
18=54-36=4\cdot54-198=4\cdot252-5\cdot198.
\]

检查系数时直接代回原式；仅算出 gcd 不能代替 Bézout 系数的计算。
