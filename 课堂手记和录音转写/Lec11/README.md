# Lec11 原始材料

本目录保存 2026 年 10 月 20 日 Lec11（分裂域、有限域与有限域上的多项式因式分解）的来源材料：

- `Lec11-手写原稿.pdf`：用户提供的三页手写扫描稿（原下载文件名为“图离散lec11.pdf”，归档后按讲次命名）。页首标的是日期“10.20”，不是“Lec11”。
- `2026-10-20-转写01.doc` / `2026-10-20-转写02.doc`：两段课堂转写的原始 Word 文件。
- `2026-10-20-转写01.txt` / `2026-10-20-转写02.txt`：由 `.doc` 转出的纯文本，便于检索。

正式整理版位于 [`../../contribution/zhangjunshuo/lec11/`](../../contribution/zhangjunshuo/lec11/)。

## 内容与对应关系

- 手写稿第 1 页：域扩张回顾（$[K:F]$、素域与特征、三种造域方式、$F[x]/(f)\cong F(\alpha)$、域同态必单射、代数元/超越元、极小多项式、塔律）——对应整理版第 1、2 节。
- 手写稿第 2 页：分裂域（存在性、唯一性、$x^3-2$ 例子）与有限域（$x^{p^d}-x$ 的分裂域、根集构成域、极小多项式、$f\mid x^{p^d}-x\iff\deg f\mid d$）——对应第 3、4 节。
- 手写稿第 3 页：不可约多项式计数（$\varphi_d$、次数递归、存在性不等式）与有限域上多项式因式分解三算法（square-free、distinct-degree、equal-degree/Cantor–Zassenhaus）——对应第 4、5 节；另配零基础讲解稿 [`explainer-page3.pdf`](../../contribution/zhangjunshuo/lec11/explainer-page3.pdf)。

## 整理时的注意事项

- 手写稿第 3 页的 $\varphi_d$ 是“全体 $d$ 次首一不可约多项式之积”，不是欧拉函数；$\deg\varphi_d=dN_d$。
- 第 3 页“$x^{p^6}-x=\varphi_6+\varphi_3+\varphi_2+\varphi_1$”的加号是笔误，应为乘积。
- 第 3 页不等式的 $\sum$ 下标同时写了 $d'\mid d$ 与 $d'\ne d$（即真因子，等价于 $d'<d$）；读时注意别漏掉 $d'\mid d$。
- 第 3 页 distinct-degree 的两行只是单步说明；完整算法须用渐进除法（$\gcd(f^\ast,x^{q^i}-x)$，做完后除掉），不能直接用累积 $G_i/G_{i-1}$。
- 课堂转写为自动语音识别，误差较大（如“扩域”被识别成“括域/货运/机遇”，“倍立方”被识别成“被立方体”）；以手写稿和课程教材为准。
